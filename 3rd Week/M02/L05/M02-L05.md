
# 👩🏻‍💻 | M02-L05 - Lab: Functions and Code Organization

Fifth introductory laboratory focused on writing, calling, and reusing custom Python functions using `def`, parameters, arguments, and the `return` statement.

## Topics Covered:

* **Function Definition & Syntax**: Creating basic functions with `def`, proper indentation, and using colons (`:`).
* **Parameters & Arguments**: Passing single and multiple arguments, understanding parameter scopes, and handling direct values versus variables.
* **Return Values vs. Printing**: Differentiating between displaying output with `print()` and returning values using `return` for storage and reuse.
* **Conditional & Loop Integration**: Combining functions with conditional structures (`if`, `elif`, `else`) and collection traversal (`for` loops).
* **Code Reusability**: Structuring modular code to simplify tasks and execute multiple function calls with varying inputs.
* **Error Diagnosis**: Identifying and resolving common runtime issues such as syntax errors, incorrect argument counts, and name mismatches.
