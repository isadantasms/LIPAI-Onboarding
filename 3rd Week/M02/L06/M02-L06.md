
# 👩🏻‍💻 | M02-L05 - Lab: Files, Folders, and Simple Dataset Organization

Sixth introductory laboratory focused on handling paths, directories, text files, and `.csv` datasets using standard Python libraries without external data packages.

## Topics Covered:

* **Path Management**: Utilizing the `pathlib` module and `Path` objects to handle directories, check file existence, and retrieve current working paths (`Path.cwd()`).
* **Folder & Directory Operations**: Creating new directories programmatically using `.mkdir()` and iterating through folder contents with `.iterdir()`.
* **Text File I/O**: Opening, writing, and reading plain text files using context managers (`with open(...)`) with proper UTF-8 encoding.
* **CSV Data Handling**: Reading and writing `.csv` files using standard `csv.reader`, `csv.writer`, and `csv.DictWriter` without relying on pandas.
* **Dataset Structuring**: Organizing files and subdirectories into clean class-based structures and generating corresponding summary catalogues.
* **Error Diagnosis**: Identifying and resolving common runtime exceptions such as `FileNotFoundError`, `IsADirectoryError`, incorrect field counts, and delimiter mismatches.
