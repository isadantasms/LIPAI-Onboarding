
# 👩🏻‍💻 | M02-L01 - Dictionaries, and Simple Data Organization

Third introductory laboratory focused on data structures, practicing list manipulation, dictionary management, and data organization using native Python types without control flow statements or external packages.

## Topics Covered:

* **List Creation & Operations**: Initializing standard lists, working with empty lists, and appending new elements using `append()`.
* **Indexing & Sizing**: Accessing list elements via zero-based numeric indices and measuring collection lengths with `len()`.
* **Data Modification**: Updating list elements by index position and checking element presence using the `in` operator.
* **Dictionary Management**: Creating structured dictionaries with key-value pairs, initializing empty dictionaries, and adding or updating fields dynamically.
* **Lists of Dictionaries**: Combining structured records into lists to represent organized datasets and nested elements.
* **Error Handling**: Identifying and resolving common runtime issues such as `IndexError` and `KeyError`.
