
# 👩🏻‍💻 | M02-L01 - Lab: Variables, Data Types, Operations, and Error Tracebacks

Second introductory laboratory focused on declaring variables, checking data types with `type()`, performing arithmetic and string operations, and practicing error interpretation through real traceback examples.

## Topics Covered:

* **Variable Declaration & Naming Rules**: Creating basic variables (`int`, `float`, `str`, `bool`) and following standard Python naming conventions.
* **Type Inspection**: Using the `type()` function to identify and analyze data types such as `<class 'int'>` and `<class 'str'>`.
* **Basic Operations**: Performing mathematical calculations with numbers and string concatenation using the `+` operator.
* **Output Formatting**: Comparing `print()` comma-separated values versus explicit string casting with `str()`.
* **Type Behavioral Differences**: Observing how distinct data types alter the execution and behavior of operations (e.g., numbers vs. string representations).
* **Error Handling & Traceback Reading**: Analyzing and fixing intentional errors, including `SyntaxError`, `NameError`, and `TypeError`.
