
# 👩🏻‍💻 | M02-L01 - Lab: Google Colab, Notebooks, and First Steps in Python

Brief introductory laboratory focused on getting familiar with the Google Colab environment, understanding the structure of Jupyter notebooks, and executing basic Python code and arithmetic operations.

## Topics Covered:

* **Colab Environment**: Identifying text (Markdown) vs. code cells and running them on remote cloud infrastructure.
* **Basic Syntax & Output**: Executing simple `print()` commands and modifying messages.
* **Arithmetic Operations**: Performing basic math calculations and testing operators in Python.
* **Cell Execution Order**: Understanding variable scope and why running cells in sequential order matters.
* **Error Handling**: Identifying and fixing common syntax errors (such as missing parentheses or quotes).
* **Interactive Reflection**: Documenting learning progress and organizing structured checklists within the notebook.
