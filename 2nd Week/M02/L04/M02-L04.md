
# 👩🏻‍💻 | M02-L01 - Lab: Conditionals, Loops, and Collection Processing

Fourth introductory laboratory focused on control flow structures, conditional decision-making (`if`, `elif`, `else`), iteration mechanisms (`for`, `range`), counters, accumulators, and processing collections of dictionaries.

## Topics Covered:

* **Comparison Operators**: Evaluating simple conditions using relational operators (`>`, `<`, `==`, `!=`).
* **Conditional Branching**: Implementing decision logic with single `if` statements, binary `if-else` blocks, and multi-way `if-elif-else` chains.
* **Indentation & Block Scope**: Understanding how proper indentation defines code execution blocks and prevents syntax or indentation errors.
* **Iteration & Loops**: Traversing lists directly using `for` loops and generating index sequences with `range()`.
* **Counters & Accumulators**: Implementing tracking variables to count specific items or accumulate running totals across loops.
* **Collection Processing**: Processing structured lists of dictionaries with conditional checks to filter and analyze dataset entries.
* **Error Diagnosis**: Identifying and resolving common runtime issues such as `IndentationError`, `SyntaxError`, `NameError`, and `TypeError`.
