
# 👩🏻‍💻 | M03-L01 - Lab: Fundamental Concepts of Machine Learning

First introductory laboratory of Module 3 focused on core machine learning concepts, exploring feature representation, class balance, classification versus regression, learning paradigms, and the limitations of manual rule-based classifiers using native Python collections.

## Topics Covered:

* **Core Vocabulary**: Identifying features, target labels, continuous variables, categorical fields, and unique identifiers within dataset samples.
* **Class Balance Analysis**: Evaluating the implications of balanced versus imbalanced class distributions on model training and performance.
* **Data Representation**: Structuring tabular data (such as the Iris dataset) as native Python lists of dictionaries without external dependencies.
* **Manual Rule-Based Classifiers**: Implementing and evaluating threshold-based classification logic using `if/elif/else` statements to understand the limits of hardcoded rules.
* **Classification vs. Regression**: Differentiating between discrete categorical prediction tasks and continuous numerical estimation tasks.
* **Learning Paradigms**: Exploring supervised, unsupervised, semi-supervised, self-supervised, and reinforcement learning scenarios.
* **Error Diagnosis**: Identifying and correcting common conceptual mistakes regarding feature selection, target identification, and model generalization.
